Norconsult felles APS Client ID
Denne extensionen bruker Norconsult sin felles Autodesk APS-registrering med Authorization Code + PKCE. Før innlogging må den lokale OAuth-helperen kjøre på localhost:3000.
Registrert callback URL
Client ID er ikke en hemmelighet. Ingen Autodesk Client Secret brukes. OAuth-helperen tar kun imot callbacken og sender autorisasjonskoden tilbake til extensionen.
